# Workflows

Every workflow follows:
```
collect
  ↓
deterministic cleanup
  ↓
Jev relevance / priority gate
  ↓
LLM or specialist worker
  ↓
Jev policy/action gate
  ↓
deterministic execution
  ↓
Jev final quality/risk gate
  ↓
memory + report
```

Engines:
- Business: signals → pain → validation → opportunity → Cash/Venture.
- Career: offers → match → research → materials → approval before contact.
- Finance: market/macro → analysis → risk → DCA/opportunity proposal → human executes.
- Engineering: task → Claude/Codex → tests → Jev → PR.
- Anakalypto: topic → sources → claims → evidence → fact-check → pedagogy → visual → interactive content.
