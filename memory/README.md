# Memory Architecture

A large amount of context should be **available** while only a small, relevant subset is **injected**.

## Layers
1. Raw observations.
2. Structured entities.
3. Semantic index.
4. Jev relevance gate.
5. Working context.
6. Durable insights.

## Dream consolidation
A scheduled Memory Gardener may deduplicate, merge equivalent memories, identify contradictions, flag stale facts, promote recurring patterns, lower confidence of outdated data and preserve provenance.

It must never silently rewrite high-impact facts without provenance.

## Obsidian
Obsidian remains the human-readable knowledge layer. The machine index references Markdown notes rather than replacing them.
